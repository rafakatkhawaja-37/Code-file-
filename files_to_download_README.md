# E-Commerce Data Analytics & Quality Audit

An automated data cleaning and analytics pipeline developed to audit, sanitize, and prepare e-commerce transaction data for business intelligence reporting.

## Project Structure
```
.
├── main.py                # Main Python cleaning script
├── requirements.txt       # Project dependencies
├── Project_Report.md      # Detailed audit report
└── README.md              # Project documentation
```

## Setup & Execution

1. **Install Requirements**:
   ```bash
   pip install -r requirements.txt
   ```

2. **Run Cleaning Pipeline**:
   ```bash
   python main.py
   ```

## Output
Running the script generates `cleaned_ecommerce_data.csv`, which is fully prepared for downstream analytics and dashboard visualizations.
